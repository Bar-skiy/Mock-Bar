# Mock Bar

## Тип проекта

**Mock Bar** — это заглушка (mock-сервис), предназначенная для использования в нагрузочном тестировании.  
Сервис имитирует поведение внешнего API и позволяет гибко управлять сценариями взаимодействия.

---

## Используемые технологии

- Java 17+
- Spring Boot
- Maven
- Lombok
- SLF4J / Logback
- Docker (опционально)

---

## Назначение

Mock Bar используется как симулятор внешнего сервиса для:

- исключения зависимости от нестабильных или недоступных внешних API;
- эмуляции различных сценариев взаимодействия (ошибки, задержки, нестабильность);
- проведения нагрузочного, стресс- и chaos-тестирования;
- воспроизведения заданных условий с полной управляемостью ответов.

---

## Основные возможности

- Поддержка REST-эндпоинтов
- Конфигурируемые задержки, коды ответов и содержимое тела ответа
- Логирование всех входящих запросов
- Гибкая настройка поведения сервиса

---

## Сценарии применения

- Нагрузочное тестирование с использованием JMeter, k6, Gatling и др.
- Chaos testing в тестовых или изолированных средах
- Интеграция в CI/CD пайплайны
- Локальная отладка без зависимости от реальных внешних систем

---

## Структура проекта

Проект реализован на Spring Boot с использованием Maven.  
Может запускаться локально или в Docker-контейнере, при необходимости.
